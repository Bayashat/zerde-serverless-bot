# Memory V2 模型调用前的标签复核冻结记录

本记录仅覆盖合成标签及离线测量契约。全部文本和身份均为 AI 编写的合成输入。审阅与以下修正在未调用或查看真实模型结果时完成；不表示模型质量、部署、AWS、Telegram 或真实群验收通过。

## PRE 审阅、批准与修正

独立 memory 审阅代理复读三种源语言全部 60 组 profile（120 条事实）、40 个操作分支以及四个语言切片的 240 场景。最初语料语义指纹为 `f622ef63d452823ddef322221a0b55eb8b38f238be896e28798e1db566778291`。独立主代理随后逐项检查所有 41 个有别名的原句及 58 个候选形式，批准该有限名单；实现不得读取真实模型返回值来追加别名。

模型调用前发现并修正：

1. **证据终标点。** 原 gold 要求整句连同句号，合法、完整、精确原文去掉句号仍会被评分器判为无来源。现在只从 gold 支持跨度尾部去掉 `. ! ? 。 ！ ？`，保留主语、谓语、否定和限定词；不接受任意子串相交，不改变评分器的完整覆盖检查或 100% 来源门槛。
2. **有限等价值。** 例如 `electrical engineering diploma` 与源句 `diploma in electrical engineering`，俄语职业工具格，以及哈语城市处所格。依据源语言、原句、字段、facet 和规范值匹配静态批准名单。没有宽泛语义、词干或翻译匹配；学历类型/级别、职业资历、国家/城市、不同技术及偏好枚举不能混同。
3. **明确教育问题。** 俄语 `Какую специальность этот участник сам сообщил?` 可被理解为职业，导致已有职业的 7 个 ru/mixed 场景被错误要求拒答。俄语模板统一改为 `Что этот участник рассказывал о своём образовании?`，共更新 27 个派生问题；仍查询缺失的 education 字段，支持集合和预期拒答不变。
4. **真实旧消息编辑输入。** 四个 `*-056` 原先实际为旧 message。现为 `type=edit`、`source_version=2`，原发送时间在启用前，编辑时间在启用后；期望仍是不学习。
5. **管理员确认输入。** 独立复核发现固定 confirmation 生成器擅自删除规则值末尾句号。主代理明确批准保留管理员提供的完整值。仅移除该生成器的 `rstrip('.')`，gold 规则值和评分器不变，也不给群规则添加任意释义别名。

原语言事实的作者、群、规范值、否定/替换结果、时间状态、问题支持集合与答案类别均未改变。源消息正文完全不变。变化是 764 个重复 checkpoint 事实观测的证据尾标点、256 个事实观测附上的受控别名、27 个明确教育问题和 4 个历史编辑事件元数据；不是按预测结果增删 gold。

## POST 验证及边界

实现代理复核了生成前后全部 240 场景差异，确认上述变更范围；保持 516 个唯一 gold facts、256 个未知问题及每语言的所有原数值门槛。补充的定向测试验证全部 58 个别名、学历/国家/资历/跨源语言反例、缺主语及否定/引用/无关来源不能放行、教育问句、历史编辑和管理员规则值。

最终 `test_memory_gold_review.py`、`test_memory_eval.py`、`test_memory_domain_replay.py` 合计 **112 项通过（34.44 秒）**，本次 12 个变更文件的 pre-commit 检查通过。没有修改生产模块、评分器、部署配置或执行真实 provider 调用。

实际领域代码加 Moto 的四语言旧编辑回归证明其不进入 RAW 或模型上下文；实际管理员确认回归证明完整规则值被唯一 writer 保存。它们仍是本地合成执行，不是 AWS 或 Telegram API 验收。主代理最终独立 diff 审阅通过：逐场景对比合并基线的 240 项 JSON，只允许本文件列出的四类语料修正，确认其他源正文、gold 身份、值、时间和预期行为完全不变；独立执行 22 项标签专项测试通过（3.48 秒）。这仍不表示真实模型验收通过。

242 条固定响应只由原有 `fixture_authoring` 读取 `project_scenario` 的无 gold 投影重建。所有 extraction 响应保持不变；只有一个改写后的问题输入记录及三条管理员 confirmation 值变更。教育问句重述后，刻意有限的 toy 分类器可能仍选错字段；没有为提高其分数补规则。固定响应的 FAIL 必须如实保留，不能当作供应商效果。`accepted_values`、预期答案和事实支持集合仍不能到达 provider。

这份有限名单不承诺覆盖所有自然表达。语料是 60 类模板/分支的四语言对照，mixed 主要是消息间语言切换，不能代替真实群中长对话、口语、错别字、单句夹杂或七天样本验证。
