# FIX: 停用自动互动并隔离旧记忆路径

父工单：https://github.com/Bayashat/zerde-serverless-bot/issues/157

## 目标与问题

现有 /agent off 同时关显式问答，ambient 不遵循同一控制；legacy task 和旧 ask payload 可继续发言或复活记忆。

## 已批准契约

显式问答与学习/社交开关解耦；所有自动社交路径关闭，包括channel posts；旧memory/summary/vector/proactive/reaction/ask任务按明确版本隔离，旧import/backfill拒绝apply。新无记忆ask不读取旧profile/vector/AGENT_REPLY上下文，媒体临时能力保持。

## 所有权与范围

- Owner：执行本工单的主实现者；共享入口和infra由集成负责人协调。
- 允许：`src/bot/services/group_agent.py`, `src/bot/services/group_memory.py`, `src/bot/services/group_memory_processor.py`, `src/bot/services/sqs_task_router.py`, `src/bot/services/handlers/commands.py`, `src/bot/services/repositories/sqs.py`, `src/bot/services/vector_memory.py`, `dev/tools/import_telegram_history.py`，及直接相关测试/文档。
- 禁止：不改captcha/spam业务语义；抽奖按后续用户要求在Z19移除，不删除数据。停旧写入是切换guard，不是Memory V2完成。
- 依赖：无，可在独立写入范围内并行。

按 PLAN 删除/隔离问题路径，不增加同等地位的第二事实或状态来源。每个分支以独立PR交付；代码、部署读回、合成、真实验收分别记录。若缺真实证据，保留 IMPLEMENTED_UNPROVEN，不因单元测试通过关闭产品验收。Memory相关失败只能回无长期记忆问答，不能恢复legacy知识。
