# FIX: 旧记忆清零工具和切换演练

父工单：https://github.com/Bayashat/zerde-serverless-bot/issues/157

## 目标与问题

历史import污染混合profile，无法可靠按import_run拆开；队列/向量/副本会残留旧资料。

## 已批准契约

dry-run默认；精确目标/类型/key/vector manifest；加密备份7天；旧writer全部停且inflight结束；按allowlist删，独立vector enumeration；queue按类型，副本生命周期分别登记；新epoch只在验收后开启。

2026-09-11用户取消抽奖：显式 `retired_contests` chat/root scope允许清理退役META、参与者、规则alias及精确对应全局outbox（含已缺META的孤儿）。各行须通过规范key/kind/主体关联校验并进入同一备份/manifest；未知shape中止，outbox最后删除。额外核验旧contest writer、recovery规则及旧任务停止；规则已删除时仅明确ResourceNotFound可作为ABSENT读回。公共memory forget权限不扩张。
