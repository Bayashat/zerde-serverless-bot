# FEATURE: Memory V2 身份、事实和控制契约

父工单：https://github.com/Bayashat/zerde-serverless-bot/issues/157

## 目标与问题

当前profile/facts/vector分别解释知识，身份与修订无唯一真源，旧记忆与contest混表。

## 已批准契约

独立V2表；唯一controls/fact writer；SourceEvent时间/编辑版本/哈希/epoch；事实字段白名单、证据和当前状态；profile只读facts。新群learning默认关闭，只有显式激活写started_at。

## 所有权与范围

- Owner：执行本工单的主实现者；共享入口和infra由集成负责人协调。
- 允许：`src/bot/services/memory_v2`, `infra/components/memory_v2.py`, `infra/stack.py`, `src/bot/app.py`，及直接相关测试/文档。
- 禁止：不把退役抽奖数据搬入新版，不建另一可写profile/cache或vector索引，不部署后默认导入历史。
- 依赖：Z01 #158, Z04 #161

## 验证与完成证据
