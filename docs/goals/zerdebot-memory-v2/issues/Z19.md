# CHORE: 移除实验性抽奖功能

父工单：https://github.com/Bayashat/zerde-serverless-bot/issues/157

## 目标与问题

用户于2026-09-11明确取消实验性抽奖，要求直接在PR #204移除，随后由用户审阅、批准及合并。原本抽奖SDK事务修复PR #181被功能退役取代；历史故障证据保留在AUDIT/EVIDENCE，不再保留抽奖功能来验收这项修复。

## 已批准契约

移除抽奖命令、参与者/根消息观察、规则/结果/reaction输出、repository和定时TTL恢复。旧PROCESS_CONTEST_TTL_SWEEP/RECOVERY任务在任何查表、发信、再投递前无副作用消费。抽奖残留不进入新记忆；显式退役chat/root清单可在Z10工具中备份及清理，公共forget仍不扩大到非记忆记录。未知行、settings、验证码、群统计和其他业务受保护，不删共表、不purge混合队列。

## 所有权与范围

- 允许：contest相关src/infra接线、测试、legacy_cleanup显式scope、memory_eval业务fixture、相关文档/工单。
- 移除旧功能实现和专属测试；保留test_application_wiring中的其他业务注入和主入口验收。
- 不修改新记忆的语言gold或实际provider逻辑来提分，不删除其他业务。
- 本次交付在现有PR #204，不合并、不部署，不执行AWS数据/资源删除。
- 依赖：无；Z10的退役数据清理须读回Z19实际发布和停写证据。

## 验证与完成证据

当前源码不存在可执行contest模块/命令/恢复schedule；旧任务与正常任务混合投递时旧任务无副作用，其他业务继续工作。原生SDK/Moto清理演练验证显式root删除、孤儿alias/outbox、shape拒绝、备份续跑以及无关数据整行hash保持。全量pytest、hooks、实际ARM64打包与CDK模板检查；独立correctness/maintainability复审。真实部署/旧数据清理另记，不以代码删除冒充线上删除。

## 替代路径、回滚与状态

不提供重新启用抽奖的开关；回滚版本也须保留退役任务隔离，不恢复旧writer或定时器。Memory V2故障回无长期记忆显式问答。现有参与者/结果等历史数据只通过精确manifest处理，未实际清理前不得宣称已经删除。
