# FEATURE: 可靠消息摄取与后台恢复

## 目标与问题

先保存MSG后enqueue可永久丢任务，旧task正文可绕过删除，spam清白结果未必恢复摄取。

## 已批准契约

message+pending同事务；新独立Q/DLQ/worker；payload只refs/schema2/epoch；5min恢复；PENDING/LEASED/DONE/EXPIRED/FAILED及lease/retry；source逻辑30天校验；spam终态安全后幂等恢复观察。

## 所有权与范围

- Owner：执行本工单的主实现者；共享入口和infra由集成负责人协调。
- 允许：`src/bot/services/memory_v2`, `src/bot/memory_worker_main.py`, `src/bot/webhook.py`, `src/bot/services/spam/processor.py`, `infra/components/memory_v2.py`，及直接相关测试/文档。
- 禁止：不将记忆负载挤进验证码主队列；所有批次同群，最多20条/8k输入，120秒worker和合适visibility；不能把TTL延迟当数据有效。
- 依赖：Z05
